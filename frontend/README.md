# ZonePilot Frontend

React 19 ops dashboard + driver PWA (Leaflet maps, STOMP live ticks, offline queue).

- Run: `npm install && npm run dev` (needs `VITE_API_BASE_URL`, e.g. `http://localhost:8081`)
- Build: `npm run build`
